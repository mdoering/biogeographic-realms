= Global biogeographic realms from GBIF occurrences

An attempt to divide the whole globe, land and sea, into large non-overlapping realms from GBIF occurrence records alone,
defined by endemism at species, genus and family level, and to test how well existing schemes hold up against the result.

This is a scientific analysis, not a gazetteer. See link:docs/design.md[the design] for the method, and
link:DECISIONS.md[the decision log] for every change to it.

== Setup

Requires Python 3.13 and https://docs.astral.sh/uv/[uv].

[source,bash]
----
uv sync
uv run pytest
----

== Reproducing the critique of Costello et al. 2017

Needs R on the path, because the published result depends on how R's `hclust` breaks ties.

[source,bash]
----
uv run python scripts/fetch_costello.py
uv run python scripts/costello_repro.py
----

== Preparing the GBIF download

[source,bash]
----
uv run python scripts/check_release.py   # which COL release GBIF production uses
uv run python scripts/test_patterns.py   # sample real records per text term
uv run python scripts/write_queries.py   # generate and validate queries/, submitting nothing
uv run python scripts/fetch_reference.py # COL, WCVP, WRiMS, GRIIS, gazetteers, coastline, Natural Earth admin-1, the TDWG level 3 polygons (WGSRPD, no stated licence, see DECISIONS.md) and ISEA3H grids into data/reference, each licence noted in manifest.json where it was found
uv run python scripts/request_exports.py # list the ChecklistBank exports fetch_reference.py found missing (or, with --griis-extended, the GRIIS lists with no extended export); --submit asks production for them with your account
uv run python scripts/check_reference.py # rank coverage, and what WCVP's empty value means
uv run python -I scripts/check_natives.py # join WCVP, GRIIS and WRiMS to COL ids by name and print each source's match rate (matched, ambiguous, unmatched, by names and by rows); asks GBIF's match API for the names of any source with over 10% unmatched, saves the placed ones to data/reference/gbif_fallback.parquet with the COL release in its metadata (load_references refuses it for another release), then loads References (about 16 GB, 1 minute) and writes results/natives.json. --no-references skips the load
uv run python scripts/check_grid.py      # ISEA3H resolutions 5 to 7: cells, neighbours, area and land, and the median cell area
uv run python scripts/write_split.py     # freeze the family split for COL 315557 into data/split and print its hash
uv run python -I scripts/check_columns.py data/gbif/<key>.zip # a Denmark SQL download: COL's status values, accepted species and cell codes against the grids
uv run python -I scripts/ingest.py data/gbif/<key>.zip --resolution 6 # stream a SQL download into Parquet in data/gbif/<key>/, check it and write results/pilot/res6/qa.json, exiting non-zero if a pass mark fails
----

== Cleaning the counts

[source,bash]
----
uv run python -I scripts/clean_counts.py --counts data/gbif/<key> # layers 1 to 4 on half A, once per WCVP mode (native_only, introduced, off), into results/clean/res<r>/<mode>/: presence, removed (every row taken out or moved, with its layer and rule), unplaced, and the removal summaries; report.json holds the removals per layer and rule, the effect of each WCVP mode, the zero-area fold, the Caspian check and the provisionally accepted twins. About 20 GB at the peak, 1 minute
----

== Measuring scale

[source,bash]
----
uv run python scripts/benchmark.py --species 1000000 # time the cell-taxon matrix on a synthetic grid, about 6 GB at 1M species
uv run python -I scripts/pilot.py --counts data/gbif/<key> --workers 12 # run the pipeline once on half A at resolution 6, time and weigh every stage, project resolution 7 and write results/pilot/res6/measure.json
----

== Layout

`src/realms/`:: The analysis package.
`scripts/`:: Runs that produce results.
`queries/`:: The generated occurrence queries, and the SQL of the Denmark column check.
`tests/`:: Unit tests.
`data/`, `results/`:: Downloads and outputs. Neither is committed.
